# ThaiFlex

แอปคำนวณแคลอรี่และสารอาหารเมนูไทย (PWA ไฟล์เดียวชุด ไม่ต้องติดตั้งอะไร) — ข้อมูลเก็บในเครื่องผู้ใช้เท่านั้น

## ไฟล์ในโปรเจกต์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าแอป |
| `style.css` | สไตล์ + โครงแอป (App Shell v7: เมนูล่างและการ์ดตัวละครล็อกนิ่ง) |
| `app.js` `core.js` `data.js` `art.js` `avatar.js` | ตรรกะแอป, ข้อมูลอาหาร, ภาพวาดสถานที่, ตัวละคร |
| `sw.js` | Service Worker (ใช้งานออฟไลน์) |
| `manifest.webmanifest` | ข้อมูลติดตั้งแอปบนหน้าจอหลัก |
| `icon-192.png` `icon-512.png` | ไอคอนแอป |

## ขึ้น GitHub Pages
1. สร้าง repository ใหม่ (เช่น `thaiflex`) แล้วอัปโหลดไฟล์ทั้งหมดไว้ที่ราก (root)
2. ไปที่ **Settings → Pages**
3. Source: **Deploy from a branch** → Branch: `main` / `/ (root)` → Save
4. รอ 1–2 นาที ลิงก์จะเป็น `https://<ชื่อผู้ใช้>.github.io/thaiflex/`

## ติดตั้งบน iPhone
เปิดลิงก์ใน Safari → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**

## อัปเดตแล้วมือถือยังเห็นของเก่า
แก้เลขเวอร์ชันในบรรทัดแรกของ `sw.js` (`thaiflex-v9` → `v10` …) ทุกครั้งที่แก้ไฟล์
